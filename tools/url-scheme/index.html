URL Scheme 转换工具

将传统 URL 转换为可直接跳转应用的 URL Scheme

使用说明

  • • 输入每行一个 URL，支持多个 URL
  • • 选择对应的转换规则（如 Pixiv、Twitter 等）
  • • 点击转换按钮生成 URL Scheme
  • • 点击测试按钮可在浏览器中测试跳转
  • • 注意：URL Scheme 在移动设备上效果更佳
